## v0.1.0 (2026-09-16)
First public release.

- Rotation queue of your next 1–5 abilities with cooldown sweeps, plus a glow on the matching action
  bar button (default bars, ElvUI, Bartender4, Dominos).
- Gear-aware playstyles for Paladin (Exodin, Wrath-like, Shockadin, Protection) and Mage (Fire, Frost,
  Arcane healer): set bonuses, engraved runes, shoulder souls, weapon type and level are read in game.
- First-run setup wizard, an in-game rotation editor with live condition preview, and import/export
  strings for sharing rotations.
- Any class can register spells from its spellbook and build a rotation without shipped class data.
- Rotation modes (Auto / Single / Cleave / AoE) driven by an enemy count from nameplates, with a
  keybinding and `/elm mode` to override.
- Per-ability cues: glow styles, textures, sounds and chat announcements; readiness checks for seals,
  auras and buffs; a fight tracker with history.
- Elmira never casts for you. It is a visual guide only.
