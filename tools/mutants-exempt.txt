# Files, or the literal option-table fields in a file, tools/mutants.sh may skip, one per line, each
# with the scope and the reason it cannot be usefully mutation-tested. An entry here is a claim
# someone made and can be argued with. An undeclared gap is just a silence, which is what this file
# exists to prevent -- so keep it short and delete entries as they are earned. ADR-0016.
#
# Format: <path> <file|fields> <reason...>
#   file    every line of the file is skipped.
#   fields  only literal option-table fields (key = "string"|number|true|false|nil|L[...],) are
#           skipped -- every set/get/hidden/disabled closure and every function stays mutated.
# An entry naming a file that does not exist, or missing a scope or a reason, aborts the run before
# any mutation runs: a silent exemption is the failure mode this file exists to prevent, same as
# tools/coverage-exempt.txt.
